Follow the paw prints

A day with the flock

Six moments from a normal day running coding agents. Every picture below is the real app, with demo projects.

  1. 1

    Gather the flock

    Each repository gets a row, and every worktree nests under it with its branch, pull request and changes. Agents sit in their own list, so you see at a glance that Claude is editing ledger-api while Codex fixes rounding next door.

    Start a new worktree with claude or codex already running in it (macOS and Linux).

  2. 2

    Read what they made

    Open Review Changes for a pull-request-style diff of the work. Click a line, write what you think, and send your notes straight back to the agent that wrote it. When you are happy, the Git menu commits, pushes and opens the pull request.

    Review works on local checkouts. Pull request badges need a GitHub sign-in.

  3. 3

    Point at the thing

    Agents open their previews in a browser tab beside the terminal. Instead of describing which button is wrong, pin a note to it. Your notes, with the element they belong to, go back to the agent.

    Browser tabs and annotations: macOS and Windows. On Linux, pages open in your system browser.

  4. 4

    Move to greener pastures

    Laptop getting warm? Teleport a worktree, its tabs, running programs and agent sessions to a bigger machine over SSH or to a cloud sandbox, and bring it back later. Smart Dispatch picks the least busy machine for new work.

    Teleport, Fan-out and Smart Dispatch run from macOS and Linux clients.

  5. 5

    Watch the grass

    Agents eat plan limits. Sheprd reads usage for 85+ AI services and shows the one closest to its limit in the status bar, next to CPU and memory for every machine.

    Each service needs its own sign-in or key on the machine it runs on.

  6. 6

    Make the field yours

    Hundreds of themes, sidebar layouts from roomy to minimal, your fonts and your shortcuts. Add your own status items or panels with small Luau mods, and schedule nightly jobs that only run after you approve the script.

    English is the only language that ships today; translations are planned.

New to all this?

Four friendly answers

What is a coding agent CLI?

A program like Claude Code, Codex, Gemini CLI or OpenCode that runs in a terminal, reads your code and makes changes when you ask. Sheprd does not replace them: it gives each one a home, shows what it is doing and helps you check its work.

What is a worktree, and why one per agent?

A Git worktree is a second (or tenth) checkout of the same repository on another branch. Give each agent its own and they never trip over each other's files. Sheprd creates them, nests them in the sidebar and cleans them up safely.

What runs my terminals?

A small terminal server: Herdr's herdr server, or herdr-core, which ships with Sheprd. It keeps your agents running even when the window is closed. Sheprd is an independent client for these servers, not part of the Herdr project.

Does it cost anything, and does it phone home?

Sheprd is free and open source under Apache-2.0. Sign-ins live in your system keychain, logs and crash reports stay on your computer, and updates are signed.
