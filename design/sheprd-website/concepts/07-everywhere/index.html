For macOS, Linux and Windows · open source

Your agents, wherever your machines are.

Sheprd is a native desktop app for running a team of coding agents. Start them on your laptop, a build box over SSH, a container or a cloud sandbox, keep them all in one window, and answer them from your phone.

Install Sheprd See how machines connect
  • 3 desktop OSes, x86_64 and ARM64
  • SSH, WSL, containers, cloud as devices
  • Any phone through the remote-control web app

01 Your desk

A native window on the computer you sit at.

Sheprd is written in Rust on GPUI and draws every terminal cell itself, on macOS, Linux and Windows. Every agent CLI you already use runs in its own pane, with idle, working, blocked and done dots on every tab and sidebar row.

  • Worktrees in the sidebar. Each checkout nests under its repository with its PR, diff counts and agent status.
  • Overview. Agents waiting on you, failed runs and finished work, in one list.
  • Sessions outlive the window. The terminal server owns every process; close or update the app and agents keep running.

02 Your machines

Put the agent where the cores are.

Every machine joins the same sidebar. The All Devices view shows spaces and agents across them, with a two-hour activity heatmap and load per host.

Saved SSH machines

One shared login per host, MFA hosts through your own ControlMaster, suggestions from your SSH config, Tailscale peers and Bonjour.

Shipped Windows: no connection sharing

WSL distributions

Herdr inside WSL appears as a device, with load, plan usage, ports and checkpoints, and path-mapped file drops.

Shipped Windows

Containers per agent

Docker or Podman containers with resource limits, no-new-privileges and idle auto-stop, built from your project's Dockerfile or devcontainer.

Shipped macOS and Linux clients

Coder and Azure

Create Coder workspaces, Azure VMs or Container Apps sandboxes as devices, with setup scripts that install the agent CLIs.

Shipped macOS and Linux clients

More cloud sandboxes

Daytona, Fly Sprites, Boat, Railway's temporary VMs and self-hosted OpenSandbox.

Experimental macOS and Linux clients

Ports, wherever they are

Listening ports show up per workspace. Click one to open it in a browser tab, tunnelled from remote machines automatically.

Shipped Forwarding: macOS and Linux

Three ways to spread the work

Sheprd ranks connected machines by spare cores and load, then creates the worktree on the best one, shipping a Git bundle when the host does not have the branch.

03 Your pocket

Answer the agent from the sofa.

Turn on remote control and your computer serves a small installable web app to your phone: chats, the questions agents are waiting on, and Web Push notifications. Approving one phone also enrols it on the SSH and cloud machines your computer uses.

  • Opt-in
    Remote control web appAny modern phone browser, Android included. Off until you enable it.
  • Opt-in
    Pairing approved on both screensQR plus a matching six-digit code, then Allow on the desktop. Its own certificate authority, over your LAN or Tailscale.
  • TestFlight beta
    Native iPhone and iPad appMerged home across computers, chat, dictation, a terminal with key rows, iPad split view. iOS 26. No public link yet.
  • Experimental
    Live Activities, widgets, Apple Watch, nearby pairingBuilt into TestFlight builds; not yet verified on real devices.
  • Planned
    Native Android appAndroid uses the web app and Web Push today.

05 Install

Pick the device in front of you.

Releases are still published under the Herdr UI name from the current channel below. Sheprd-named downloads at github.com/sheprd-labs/sheprd are a future destination.

macOS 14.2 Sonoma or newer, Apple silicon or Intel (universal, signed and notarized). Current channel

brew install penso/tap/herdr-gpui

x86_64 and ARM64; installs a .deb, .rpm or Arch package. Needs glibc 2.39+ and a Vulkan driver. Current channel

curl -fsSL https://herdrui.dev/install.sh | sh

x86_64 and ARM64, per-user, no administrator rights. PowerShell: Current channel

irm https://herdrui.dev/install.ps1 | iex

Builds from source with the flake, x86_64 and ARM64 Linux. Never updates itself. Current channel

nix run github:penso/herdr-gpui

Any phone: enable Settings › Remote control on your computer, scan the QR code and approve on both screens. The web app installs to your home screen.

iPhone and iPad: native app in TestFlight beta for internal testers; no public link yet. Or build it from source with your own Apple team.

Sheprd is an independent, open-source (Apache-2.0) client for Herdr's terminal servers (herdr server and herdr-core). It is not made, endorsed or supported by the Herdr project.
