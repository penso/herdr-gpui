Product datasheet

Run a team of coding agents from one native window.

Sheprd is an open-source desktop application for running coding agents in parallel worktrees, across local, SSH and cloud machines, with review, checkpoints and pull requests built in.

§2 Operating procedures

Six workflows the application is built around. Steps reference shipped features unless marked.

2.1 Issue to pull request

  1. Open Issues: GitHub, GitLab and Beads across every repository in the window.
  2. Dispatch agent: choose agent, model and branch; a worktree is created and the agent starts.
  3. Review Changes: leave line notes, Send to agent.
  4. Git menu: Commit, Push, Create pull request, Merge.

2.2 Fan-out and compare

  1. One prompt to several agents and lanes, optionally across hosts.
  2. Compare results; keep one; the rest are removed.
  3. State persists across a crash.

macOS and Linux clients

2.3 Move the work

  1. Smart Dispatch ranks hosts by spare cores and load.
  2. Teleport moves commits, changes, tabs, programs and agent sessions; and back.
  3. Ports are tunnelled back to a browser tab.

macOS and Linux clients

2.4 Roll back an agent

  1. A hidden Git checkpoint is written at every agent turn (newest 50 per branch).
  2. Diff any checkpoint; restore from the workspace menu or CLI.

2.5 Answer away from the desk

  1. Enable remote control; pair with QR plus matching code; Allow on desktop.
  2. Web Push arrives; answer the question from the phone.

Opt-in

2.6 Automate the routine

  1. Write a Luau automation: pull, test, start agents, notify.
  2. Approve the exact script; it runs on its schedule within its caps.

§3 Architecture

Dependencies point downward: interface → services → connection → wire. Protocol and client crates never depend on the UI toolkit. Crate names keep their current herdr- prefix.

§5 Trust model

Trust model
RefConcernBehaviour
5.1UpdatesEd25519-signed release manifests; separate download and install approvals; Homebrew, APT, DNF and pacman installs update through their package manager. Windows updates require signed builds.
5.2SecretsTokens in the macOS Keychain, Linux Secret Service or Windows Credential Manager; a private 0600 file only when chosen. Teleport can lend the GitHub CLI token to a destination that cannot reach GitHub, and its review says so first.
5.3Logs and crashesLogs and crash reports stay on this computer and are never uploaded; diagnostic bundles are redacted and shared only by you.
5.4AutomationsRun only after a person approves the exact script text, within required caps on agents, tokens per day and wall time.
5.5Agent CLIDestructive or outward actions requested over the control socket open the app's own confirmation dialog. The socket is per user (Unix socket, or a named pipe restricted to your SID).
5.6Phone pairingQR plus a matching six-digit code on both screens, then Allow on the desktop. TLS from the daemon's own certificate authority, pinned by fingerprint; works by LAN IP or Tailscale.
5.7Terminal contentTreated as untrusted: escapes are never executed, untrusted link schemes ask first, OSC 52 clipboard accepts bounded UTF-8 text only.
5.8SessionsThe terminal server owns processes. Closing, detaching or updating the app leaves agents running; closing a workspace with unpushed work asks you to type close.
