~/agents ❯ sheprd --help

Sheprd runs a team of coding agents from one native window.

Open source · Rust + GPUI · macOS, Linux, Windows · x86_64 and ARM64

USAGE
  Open the app. Run every agent CLI you already use, side by side.

WHAT IT KEEPS IN ONE WINDOW
  workspaces   every checkout and linked worktree, with agent status
  agents       Claude Code, Codex, Gemini, Copilot, OpenCode, any terminal agent
  machines     local, SSH, WSL, containers, cloud sandboxes
  issues       GitHub, GitLab and Beads, dispatched straight to agents
  review       diffs with notes the agent receives, then commit, push, PR
  browser      previews beside the terminal, annotated for the agent
  phone        remote control from any phone browser (opt-in)

SEE ALSO
  overview  fan-out  review  checkpoint  teleport  browser  features  install

~/ledger-api ❯ sheprd fan-out "add a Currency type" --agent claude:2 --agent codex

Fan-out: one prompt, several agents, keep the best.

Opens the fan-out dialog prefilled; you start it there. Each lane gets its own worktree, optionally on another machine. Compare, keep one, and the rest are cleaned up. Smart Dispatch picks the least-loaded host.

macOS and Linux clients

~/ledger-api ❯ sheprd review

Review: notes on the diff go straight back to the agent.

PR-style review of uncommitted or branch changes, unified or split. Then commit, push, create and merge the pull request from the title-bar Git menu.

~/ledger-api ❯ sheprd teleport --to gpu-runner

Teleport: move a live worktree to a bigger machine.

Commits, uncommitted changes, tabs, splits, running programs and agent sessions move together. Teleport back later. The command only opens the dialog; you confirm there.

Browser: the agent opens the page, you point at what to fix.

Pages open beside the terminal. Pin notes to elements, text or regions and press Send to agent; the agent waiting on feedback gets them, screenshots included on macOS.

macOS and Windows · Linux opens your system browser

~/agents ❯ sheprd usage

Usage: plan limits for 85+ AI services.

The services closest to their limits sit in the status bar; click one for details. Read on the selected host, so a remote machine's sign-ins count too. sheprd system prints CPU, memory, disk and uptime.

~/agents ❯ sheprd remote pair

Remote: answer your agents from a phone.

Your computer serves an installable web app: chats, the questions agents wait on, and push notifications. Pairing is approved on both screens, over the LAN or Tailscale, with the app's own certificate authority.

Opt-in, any phone browser · native iPhone and iPad app: TestFlight beta · Live Activities, widgets, Watch: experimental

~/agents ❯ sheprd automation approve nightly.luau

Automations and mods: Luau, sandboxed, approved by you.

-- nightly.luau (from docs/automations.md, abridged)
herdr.caps { agents_per_run = 2, tokens_per_day = 2_000_000, wall_time = "3h" }

herdr.at("03:00", { tz = "Europe/Paris" }, function(fire)
  pull("main")
  local v = sh("just ci", { check = false })
  if not v.ok then
    agent { harness = "claude", prompt = "Nightly validation failed. Fix it." }
  end
end)

The command approves nothing: it opens the plan, caps and content hash in the app for you to approve. Mods add status items, sidebar sections, panels, palette commands or whole apps, and reload live.

~/agents ❯ cat INSTALL

Install — Homebrew keeps its existing tap and token

# macOS 14.2+, universal

brew install penso/tap/herdr-gpui

# Linux x86_64/ARM64 · APT, DNF, pacman

curl -fsSL https://sheprd.org/install.sh | sh

# Windows x86_64/ARM64 · PowerShell

irm https://sheprd.org/install.ps1 | iex

# Nix · builds from source

nix run github:sheprd-labs/sheprd

iPhone, iPad: TestFlight beta, no public link yet; build from source today. Any phone: turn on remote control (opt-in) and scan the QR code.
