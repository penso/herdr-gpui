The real window

Sidebar of workspaces and nested worktrees, agents grouped below, terminals natively painted, usage and load in the status bar.

[01]

Six loops you run every day

01 Triage

Overview lists agents waiting on you, failed runs and finished work. Snooze, pin, reopen a finished Claude, Codex or opencode session.

cmd Overview · status bar usage · Devices heatmap

02 Dispatch

Issues from GitHub, GitLab and Beads. Pick one, choose an agent and model, get a worktree with the agent already running.

cmd Issues → Dispatch agent

03 Fan out

One prompt across several agents and machines. Compare, keep one, the rest are cleaned up. Survives a crash.

where macOS and Linux clients

04 Review

PR-style diff of uncommitted or branch changes. Notes on lines go back to the agent. Commit, push, open the PR from the title bar.

where local checkouts

05 Roll back

A hidden Git checkpoint at every agent turn, newest 50 per branch. Diff any of them, restore one in a click.

cmd sheprd checkpoint list|diff|restore

06 Answer from anywhere

Your computer serves a phone web app: chats, questions, push. Pairing approved on both screens, its own CA, LAN or Tailscale.

status Opt-in iOS TestFlight beta

Install

Releases come from github.com/sheprd-labs/sheprd. Homebrew keeps its penso/tap tap and herdr-gpui token, so existing installs keep upgrading.

macOS 14.2+ universal

brew install penso/tap/herdr-gpui

Linux x86_64 · ARM64 · APT, DNF, pacman

curl -fsSL https://sheprd.org/install.sh | sh

Windows x86_64 · ARM64 · PowerShell

irm https://sheprd.org/install.ps1 | iex

Nix

nix run github:sheprd-labs/sheprd

iPhone & iPad: TestFlight beta, no public link yet; or build from source. Any phone: the remote-control web app your computer serves once you enable it.

sheprd

Sheprd is an independent, open-source (Apache-2.0) client for Herdr's terminal servers (herdr server and herdr-core). It is not made, endorsed or supported by the Herdr project. About Herdr: herdr.dev.
