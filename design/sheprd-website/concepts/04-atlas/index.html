    sheprd.org / features

    Every agent. Every worktree. Every machine. One window.

    Sheprd is an open-source desktop app for running a team of coding agents on macOS, Linux and Windows. This atlas lists everything it does today, what is opt-in or still in beta, and where each piece runs.

    Requirements: macOS 14.2 or newer (Apple silicon or Intel). Linux x86_64 or ARM64 with glibc 2.39+ and Vulkan. Windows 10 or 11, x86_64 or ARM64. Phones: any modern browser for the remote-control web app; the native iPhone and iPad app (iOS 26) is in TestFlight beta.

    Install

    Releases are still published as Herdr UI from the current repository. Sheprd-named builds will come from github.com/sheprd-labs/sheprd future.

    macOS

    Universal · signed and notarized · current channel

    brew install penso/tap/herdr-gpui

    Linux

    APT, DNF or pacman · current channel

    curl -fsSL https://herdrui.dev/install.sh | sh

    Windows

    PowerShell, per-user · current channel

    irm https://herdrui.dev/install.ps1 | iex

    Nix

    Builds from source · current channel

    nix run github:penso/herdr-gpui

    iPhone and iPad

    TestFlight beta

    Native app for iOS 26, with internal TestFlight builds today. You can also build it from source with your own Apple team.

    Any phone

    Opt-in

    Turn on Remote control in Settings. Your computer serves an installable web app; pair it by scanning a QR code and approving on both screens.

    How it connects

    1. SheprdNative window: painting, input, review, browser, orchestration
    2. Terminal serverherdr server (Herdr 1) or herdr-core (Herdr 2), on this computer, an SSH host, WSL or a cloud machine
    3. Your terminals and agentsOwned by the server. They keep running when Sheprd closes, detaches or updates.

    Sheprd starts a terminal server only to connect: an installed herdr server, or the pinned herdr-core that ships with the app. It never upgrades or replaces one you run yourself.

    Sheprd · Apache-2.0 · github.com/sheprd-labs

    Sheprd is an independent, open-source (Apache-2.0) client for Herdr's terminal servers (herdr server and herdr-core). It is not made, endorsed or supported by the Herdr project.
