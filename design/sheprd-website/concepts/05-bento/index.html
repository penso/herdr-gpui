  pull("main")
  local v = sh("just ci", { check = false })
  if not v.ok then
    agent { harness = "claude", prompt = "Fix it." }
  end
end)

A day with Sheprd

Three moments where it earns its place on your screen.

  1. 9:00

    Morning triage

    Overview lists what needs you on every machine. The status bar shows plan headroom; Devices shows which box is free.

  2. 11:30

    Issue to pull request

    Dispatch an agent from an issue, review its diff with notes, then commit, push and open the PR from the title-bar Git menu.

  3. 18:45

    On the way home

    A push notification: the agent has a question. Answer from your phone; it carries on. (Remote control is opt-in.)

Sheprd

Apache-2.0 · github.com/sheprd-labs · github.com/sheprd-labs/sheprd (future)

Sheprd is an independent, open-source (Apache-2.0) client for Herdr's terminal servers (herdr server and herdr-core). It is not made, endorsed or supported by the Herdr project. herdr.dev
