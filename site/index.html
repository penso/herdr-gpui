Make room for the work.

Install Sheprd with its bundled herdr-core for local terminals, or connect to your existing Herdr daemon. Existing sessions stay where they are; closing Sheprd leaves them running.

macOS

$brew install penso/tap/herdr-gpui
macOS 14.2+, signed, notarized, universal · or the .dmg. The Homebrew token and Herdr.app name stay compatible; open with open -a Herdr.

Linux

$curl -fsSL https://sheprd.org/install.sh | sh
x86_64 and ARM64 · installs the checksummed .deb, .rpm or Arch package with APT, DNF or pacman (glibc 2.39+) · read the script · or nix run github:sheprd-labs/sheprd

Windows

PS>irm https://sheprd.org/install.ps1 | iex
x86_64 and ARM64 · installs for the current user, adds a Start menu entry · read the script · WSL daemons work too
All install options · llms.txt
The command line is sheprd. Existing configuration and legacy entrypoints remain compatible.
