# Commits without a pull request

Native macOS window captures of a synthetic fixture: no real repository, no
GitHub access. `sidebar-child` has three commits past its default branch and a
finished lookup with no pull request; its sibling has an open pull request.
`before-*` is the same fixture with nothing ahead, which is what every
branch looked like before the commits were read. Themes are Catppuccin Mocha
and Latte. Wide captures are 1,200 points, narrow ones 480.
