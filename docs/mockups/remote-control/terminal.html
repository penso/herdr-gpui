Remote control: terminal tabs on the phone

Picks: typing B (two fixed rows) · actions A (action sheet) · size D (fit to start, size for phone on demand; chosen by default, none picked).

The tabs listed as "Soon" open as real terminals. Pick one variant per row, add notes, then press Send picks. Terminal text is placeholder.

Whatever you pick, Herdr actions (split, new tab, close, zoom, focus) call Herdr's own API, as Herdr UI does, rather than typing ctrl+b keys into the pane. So they work whatever prefix you have set. Only the keys you type go to the program.

1 · Typing: the keyboard and the keys iOS lacks

Esc, Tab, Ctrl, arrows, and the symbols shells need. Ctrl is sticky: tap it, then a letter.

2 · Herdr actions: split, new tab, close, zoom, move between panes

The ◆ key from row 1 opens these.

3 · Size: a desktop pane on a phone screen

A pane is usually 120 or more columns wide; a phone fits about 45 at a readable size. Herdr sizes a pane for the client that shows it.
